## Global Constraints

- Start: git fetch origin; git switch feature/56-tag-persistence; git status --short. Do not discard user work or create implementation commits on master.
- **Approved names:** reject null/empty/whitespace-only, ISO controls (including raw tabs/newlines); trim surrounding Character.isWhitespace/Character.isSpaceChar code points; preserve case/interior spaces; permit Unicode and symbols; max 100 **Unicode code points** after trimming. Preserve first persisted casing. Never lowercase the stored name.
- **Approved schema:** singular tag table; BIGINT GENERATED BY DEFAULT AS IDENTITY; user_id BIGINT NOT NULL FK users(id); name VARCHAR(100) NOT NULL; created_at/updated_at TIMESTAMPTZ; CHECK (name <> '' AND name = btrim(name)); unique functional index (user_id, lower(name)).
- **Aggregate:** Tag extends shared.domain.BaseEntity only; owner Long scalar, immutable; no JPA User relationship, inbox, status, archive/trash/completion, association collection or cleanup behavior.
- **Uniqueness authority:** real PostgreSQL unique index, not Java check-then-insert. Issue #56 allows concurrent loser to fail with integrity/23505; graceful resolution/create-or-reuse is owned by #57.
- **Module boundary:** only tag.domain/tag.infrastructure Java production code. No cross-module production references, tag.api contract, controllers, tag application service, suggestion lookup, UI, Task/Note join tables or unrelated dependencies.
- **Testing:** PostgreSQL 17 Testcontainers, Hibernate ddl-auto=validate; do not use H2 or schema creation in tests. For JVM timezone use -Duser.timezone=UTC. From server/: ./mvnw -Duser.timezone=UTC verify (Windows: .\mvnw.cmd).
- **Delivery:** focused TDD/commits. After verified implementation push the branch, open a PR against master with Closes #56 and actual check results. Do **not** merge and do not start #57/#27. Escalate newly discovered genuine product conflicts.

## Review Focus (tests required in tasks below)

1. Raw input controls versus trimming: newline/tab anywhere rejected, ordinary/Unicode edge spaces trimmed, internal spaces retained (Task 1).
2. 100 versus 101 Unicode code points including surrogate-pair emoji; preserve non-Latin/symbol values (Task 1).
3. Raw SQL uniqueness across case variants **and** per-user isolation, illegal empty/padded/overlong values and unknown FK (Task 2).
4. JPA round trip, immutable owner/name, timestamps, owner-scoped lookup and unused Tag retention (Task 3).
5. Simultaneous distinct database transactions: exactly one duplicate-key winner, other integrity error, one committed row (Task 4).
