## Review focus

1. Actual provider bytes survive failed completion COMMIT and process restart; worker later deletes them without forgetting unresolved locator (Task 1).
2. Actual remote ACK followed by process loss before DB completion does not turn an unsettled PUT into confirmed cleanup (Task 1).
3. A DELETE initiated while unsettled cannot be retroactively credited after settlement arrives during its lease (Task 2).
4. Real UNKNOWN loser sharing a claimed parent's identity cannot cause deletion of the winning key (Task 3).
5. Genuine context shutdown stops admission while preserving unfinished durable work; fresh context resumes (Task 4).
